# New National Motor Driving School — Bhiwadi (3D Website + Live DBMS)

## Files Included (Ready to Upload)
1. `index.html` — Complete 3D Interactive Website + Dual-Panel Admin CRM (`Ctrl + Shift + A`) + Google Search Schema SEO + Live Cloud DBMS Sync.
2. `sitemap.xml` — Google Search Console Indexing Sitemap.
3. `robots.txt` — Search Engine Crawler Permission File.

## Quick Launch Steps
1. Open your GitHub repository (`new-national-driving-school-bhiwadi`).
2. Click **uploading an existing file** and drag all 3 files (`index.html`, `sitemap.xml`, `robots.txt`) directly into the repository root.
3. Import the repo in **Vercel** for instant HTTPS live hosting.
4. Press **`Ctrl + Shift + A`** on the live website (Default PIN: `1234`) -> open **Live Cloud DBMS Setup** -> paste your Firebase Realtime Database URL so uploads & bookings sync live across all mobile/desktop devices.
